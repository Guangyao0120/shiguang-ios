# 拾光 · iPhone 本地相册整理

当前0.7.0/build7，SwiftUI、PhotoKit、Vision、Speech，最低iOS17。直接引用已授权的苹果照片；本地整理不需要API，DeepSeek仅在预览确认后调用。

## 本轮修改

- 新系统原生Liquid Glass底栏；动态日夜配色，设置可选跟随系统/浅色/深色。
- 取消温度与低电量扫描拦截，开启ProMotion支持；实际帧率由iOS决定。
- 先读已保存分类，后台核对目录、生成索引与写盘；图片限并发、离屏取消。
- 默认范围、全部/100/500张、后台整理、完成通知、缓存、AI与版本设置。
- iOS26持续后台任务、旧系统短时续跑与系统安排的分批任务。系统可以拒绝或终止；保留断点，记住主动暂停。通知区分本批完成、全部结束和原件待下载。
- 详情上方待删、原件系统预览缩放及预览内待删；iCloud原件由用户主动下载。
- 截图细分、多标签、人物/行程关联、自定义分类创建与筛选；集中系统删除仍由用户确认。
- 本机视频分段转写及可编辑祝福标题；明确称呼才命名对象。可预览文字后请求DeepSeek改进。
- 出游候选增加离线城市中心与农历节日命名。

## 构建与验证

用Xcode26或更新打开Shiguang.xcodeproj。云端使用Xcode26.3/iOS26.2 SDK，24项测试通过；日夜布局截图和真机Release archive通过，已用Sideloadly覆盖安装。详细证据见[VALIDATION.md](VALIDATION.md)。

当前IPA未做App Store分发签名，不能直接上传商店。正式上架需开发者会员、正式标识和分发签名、公开隐私资料、TestFlight真机验收及审核。功能核对及官方流程见[使用与发布.md](使用与发布.md)。

## 能力边界与数据

人物身份仍手动关联；截图为可纠正建议，准确率待实际样本评估。查重非精确文件查重且有上限。城市候选仅覆盖内置部分城市中心约30公里范围，不认识的地点不猜。视频仅支持逐个发起、普通话/英语、本机模型、10分钟内；不承诺视频转写后台运行或整段视觉理解。自然语言仅支持已有标签、文字、人物和行程组合。

API Key保存在本机钥匙串，没有使用真实账户联调。后台获准时长、通知和语音效果仍需用户真机验收。原图在苹果照片，标签、转写、待删在App数据库；覆盖安装需沿用账号与应用标识，卸载会丢失私有整理记录。目前无独立备份恢复功能。
