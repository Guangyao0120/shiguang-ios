# 拾光 · iPhone 本地相册整理

0.8.4 / build13。SwiftUI、PhotoKit、Vision、Core ML、ActivityKit、Speech；最低 iOS17。原图保存在苹果照片，本地整理和搜索不调用付费 API。

## 本版调整

- 四个底部栏目：整理、出游、待删、AI。移除独立人物栏目；人像分类及已有标签、人物关联保留。
- 待删页采用复用的原生照片网格：点选、全选、长按拖动划选、反向缩小范围、从已选照片起拖取消一片、拖到边缘自动滚动。选择变化只更新可见勾选，不重载整片网格。
- 恢复和删除使用原生玻璃按钮，悬浮在可滚动照片之上；底部留有足够滚动空间，末行可完整移到按钮上方。iOS26+ 使用 Liquid Glass，旧系统采用材质回退。
- 建索引时仍可选择和恢复照片；删除前暂停索引并保存进度，再交给苹果照片确认。取消删除保留选择和待删记录。
- 描述搜索先查已有标签、OCR、视频标题、转写及行程文字，再合并已建索引的视觉候选。“人”可直接命中人像；“法官”和“法棍”使用不同映射。
- 繁简体查询同时匹配；系统翻译明确指定语言，避免反复询问繁体还是简体。首次通用描述翻译仍可能需要系统语言包。
- 首次需要画面检索且缺少索引时自动开始建立；人像等已有分类查询不会触发整库推理，已有文字结果即时显示；可暂停、持久化继续，后续索引批次自动补充当前搜索结果。不偷偷改用付费 API。
- 背景支持跟随外观、纯白、纯黑、浅绿、米色、浅粉及自定义 RGB／HEX。文字明暗自动适配；入口与卡片圆角收紧，保留系统动态字体。
- 连续整理沿用0.8.3的卡片手势、旋转弹簧和附近三张清晰图缓存；左下一张、右上一张、上滑待删、撤销及清晰原图预览保持一致。

## 已有能力

本地 Vision 截图文字、照片分类、人脸框、美食；城市／自然风光、票据合并、自定义标签与出游；视频本机转写和标题；相似照片候选；完成通知、后台任务及灵动岛进度；中文、英语、日语、韩语、西班牙语、俄语。可选 DeepSeek 接收发送前确认的文字。

整理记录使用 SQLite 增量事务保存。暂停保存已完成部分；加载失败不覆盖为空库，保存失败可重试。删除仅移除系统确认成功的照片，原件可按苹果照片“最近删除”的规则恢复。

## 构建和验证

公开仓库使用 GitHub Actions 的标准 macOS 托管运行器。完整测试通过后，在同一运行器归档 iPhone 安装包，避免重复传输模型。构建产物保留3天；不需要把 Apple ID 或 DeepSeek 密钥放进 Actions。

本轮68项模拟器检查通过：60项单元／集成测试、8项界面测试。包括真实模拟器照片读取与系统取消删除；未为测试删除用户照片。

Actions 下载的是未签名 IPA，需要本地签名后安装。正常 Xcode 开发请使用自己的唯一应用标识；侧载若会改写标识，后台许可标识也要保持一致。

## 实际限制

第一次画面索引仍需逐张处理本地照片；目录读取、Vision整理与CLIP索引是三个不同过程。小物体、遮挡、复杂场景可能漏检，相关候选不等于确定识别。视频画面暂不参与CLIP检索，但已保存的视频文字可以搜索。

iOS决定后台运行时段，不能保证无限后台或持续120Hz。真实图库上的耗时、温度与手感仍需设备使用验证；不凭模拟器声称提速倍数。

图片、OCR、索引及密钥留在手机。原始手机日志、配对凭据、图库数据库与账号私密信息不属于源码或公开构建内容。
